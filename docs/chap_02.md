# 第二章   水蒸气及其动力循环

**1. 水蒸气的定压形成过程包括哪几个过程?其T-s图上过程线下的面积表示了什么?在其汽化阶段，工质温度、焓熵等是否变化?**

- **形成过程：** 水蒸气的定压形成过程包括预热阶段、汽化阶段和过热阶段 。  
- **面积含义：** 在T-s图上，过程线下的面积代表了1kg工质在过程中所吸收（或放出）的热量 。具体来说，预热过程线下的面积代表预热热，汽化过程线下的面积表示汽化潜热，过热过程线下的面积表示过热热 。  
- **汽化阶段参数变化：** 在汽化阶段，工质的温度保持为对应的饱和温度不变 。但是随着水分不断变为蒸汽，其对应的比容、焓和熵均会逐渐增加 。  

**2. 何谓水的临界点?其临界压力、温度分别是多少?当水的压力等于或超过临界压力时，水蒸气的定压形成过程有什么不同?**

- **临界点：** 水的临界点（C点）是饱和水线与干饱和蒸汽线的交汇点 。  
- **临界参数：** 其临界温度为 374.15°C ，临界压力为 22.129 MPa 。  
- **形成过程的区别：** 当压力等于或超过临界压力时，饱和水线与干饱和蒸汽线不再分离，汽化潜热为零 。此时定压加热过程不再经历明显的汽化阶段（无湿蒸汽区），液态水在加热中直接连续地转变为过热蒸汽 。  

**3. 工质在锅炉中的吸热量和在汽轮机中的做功量如何计算?**

- **锅炉吸热量：** 锅炉属于换热器，工质在其中进行定压流动吸热，吸入的热量等于其焓的增加 。计算公式为：$q=h_{2}-h_{1}$（在标准朗肯循环中常表示为 $q_{1}=h_{1}-h_{4}$） 。  
- **汽轮机做功量：** 工质在绝热情况下流经汽轮机时对外所做的功等于工质的焓降 。计算公式为：$w_{t}=h_{1}-h_{2}$ 。  

**4. 喷管的作用是什么?如何根据压力比的大小选择喷管?为什么?**

- **作用：** 喷管是一种使流体速度得以提高的热力设备 。  
- **选择与原因：**
  - 当压力比 $p_{2}/p_{1}\ge\beta_{c}$ 时，应采用渐缩喷管 。因为在此压比下，渐缩喷管出口能获得亚音速或音速流动 。  
  - 当压力比 $p_{2}/p_{1}<\beta_{c}$ 时，应采用渐缩渐扩（拉伐尔）喷管 。因为在此压比下，该喷管出口能获得超音速流动，且在最小界面处的流速理论上等于当地音速 。（注：$\beta_{c}$ 为临界压力比 ）。  

**5. 何谓绝热节流?工质经过绝热节流后的效果是什么?**

- **定义：** 流体在管道中流动时，如果流经阀门、挡板、孔板等障碍物，流体则产生涡流和摩擦，即产生局部阻力损失，因而引起压力显著下降的现象，称为节流 。因节流进行得很快，工质来不及对外散热，故一般认为是绝热节流 。  
- **效果：** 绝热节流前后工质的焓保持相等（$h_{2}=h_{1}$） 。过程具有不可逆性，核心效果是引起压力下降（$p_{2}<p_{1}$），熵增加（$s_{2}>s_{1}$） ，最终导致工质的作功能力下降 。对实际气体还会产生温度变化（热效应、零效应或冷效应） 。  

**6. 何谓蒸汽动力循环?为什么蒸汽动力循环不采用卡诺循环而采用朗肯循环?朗肯循环是由哪几个过程组成的?它们分别在什么设备中完成?请在T-s图上熟练地画出朗肯循环。**

- **概念：** 动力循环是指工质连续不断地将从高温热源取得的热量的一部分转换成对外净功的过程 。  
- **采用朗肯循环的原因：** 蒸汽动力循环不采用卡诺循环是因为其在技术上难以实现且存在缺陷：理论上的循环效率不高；膨胀终点的湿度太大，对汽轮机的安全不利；需要的压缩机很大且两相压缩在技术上难以实现 。因此采用简单蒸汽动力装置的理想可逆循环，即朗肯循环 。  
- **过程与设备：**
  1. **1—2 过程：** 过热蒸汽的绝热膨胀作功过程，在**汽轮机**内完成 。  
  2. **2—3 过程：** 乏汽的定压放热过程，在**凝汽器**中完成 。  
  3. **3—4 过程：** 凝结水的绝热压缩过程，在**给水泵**中完成 。  
  4. **4—5—6—1 过程：** 给水的定压吸热过程，在**锅炉**（及省煤器、过热器）中完成 。

**7. 中间再热循环及回热循环与简单朗肯循环相比较，有哪些区别?再热和回热的主要作用分别是什么?**

- **再热循环：**
  - **区别：** 新蒸汽在汽轮机内作了一部分功以后，从汽轮机抽出，通过管道送到锅炉再热器中再一次进行加热，然后再送回汽轮机的中、低压缸中继续作功 。  
  - **主要作用：** 降低了汽轮机排汽的湿度，给提高初压创造了条件；若选取再热压力合适，还可以提高循环热效率 。  
- **回热循环：**
  - **区别：** 利用从汽轮机的某些中间部位抽出部分做过功的蒸汽，直接送入回热加热器中来加热锅炉给水，而不是全部排入凝汽器 。  
  - **主要作用：** 提高了锅炉中水的预热起点温度，使得工质在锅炉内的平均吸热温度也得到提高，从而使整个循环的热效率得以提升 。

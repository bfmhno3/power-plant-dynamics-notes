# 第八章   汽轮机运行

**1. 汽轮机控制系统的主要任务是什么？何谓控制系统的静态特性？同步器有何作用？**

- **控制系统的主要任务：** 根据电负荷的大小自动改变进汽量，使蒸汽主力矩随时与发电机的电磁阻力力矩相平衡，以满足外界电负荷的需要，并维持转子在额定转速下稳定运行 。  
- **控制系统的静态特性：** 在稳定工况下，汽轮机的功率和转速之间的关系，称为调节系统的静态曲线或静态特性 。  
- **同步器的作用：** 同步器是平移调节系统静态特性曲线的装置 。其主要作用包括：  
  - 汽轮机单机运行时，可以确保机组在任何负荷下保持转速不变 。  
  - 汽轮机在并列运行时，可以进行负荷在各机组间的重新分配，此时机组转速不变 。  
  - 电网频率不正常时，通过同步器平移静态特性曲线，增加或减小机组功率，以恢复电网的正常频率（即二次调频） 。  

**2. 汽轮机一般设有哪些保护装置？超速保护装置是如何起到保护作用的？**

- **一般保护装置：** 汽轮机均配有危急保安控制系统，监视并保护的参数主要包括：转速、轴向位移、排汽口真空、润滑油压和抗燃油压等 。系统一般分为：机械超速保护及手动脱扣保护系统、电气信号危急跳闸保护系统和超速防护系统 。  
- **超速保护装置的作用原理（以飞锤式为例）：** 飞锤径向安装在主轴内，其重心与主轴中心存在一偏心距 。当主轴高速旋转时，离心力使飞锤欲往外飞出 。若控制系统失灵或机组甩负荷导致转速达到 1.10~1.12 倍额定转速时，飞锤的离心力大于其锁紧弹簧的约束力，飞锤末端迅速飞出，撞击在危急遮断油路的脱扣板上，使危急油路泄压，从而强制主汽阀及调节汽阀关闭，紧急停机以保护设备 。  

**3. 汽轮机的启动方式有哪些，是如何分类的？各有哪些特点？**

汽轮机的启动方式主要按以下三种标准分类 ：  

- **按冲动转子时所用阀门的不同分类：**
  - **旁路门或自动主汽门启动：** 启动时调节汽门处于全开状态，通过控制旁路门或主汽门来控制进入汽轮机的蒸汽量 。  
  - **调节汽门启动：** 电动主汽门和自动主汽门全部开启，由依次开启的调节汽门控制进入汽轮机的流量 。  
- **按启动过程中新蒸汽参数的情况分类：**
  - **额定参数启动：** 在整个启动过程中电动主闸门前的新蒸汽参数始终保持在额定值不变 。  
  - **滑参数启动：** 电动主闸门前的新汽参数随转速、负荷的升高而滑升，汽轮机定速或并网前，调节汽门处于全开状态 。此方式的特点和优点在于：提高经济性、改善环境条件、缩短启动时间、增加安全可靠性，且启动过程易于程控 。  
- **按汽轮机启动前的金属温度高低分类：**
  - **冷态启动：** 启动前标志点（如调节级汽室等）的金属温度低于 180°C 。  
  - **温态启动：** 启动前标志点的金属温度在 350°C 左右 。  
  - **热态启动：** 启动前标志点的金属温度高于 350°C 。  

**4. 何谓汽轮机的变压运行？变压运行有哪些优点？**

- **变压运行的定义：** 变压运行（又称滑压运行）是指在调速汽门全开情况下，主汽温度基本不变，由锅炉调整主汽压力和流量，以适应负荷变动的运行方式 。  
- **变压运行的优点：**
  - **提高机组可靠性，延长使用寿命：** 变压运行时汽温基本不变，大大减小了机组各部件因温差而产生的热应力和热变形 。  
  - **适应负荷变动和调峰：** 一、二次汽温基本不变，汽轮机高温部件的温度变化较小，不会引起汽缸和转子过大的热应力、热变形 。  
  - **提高机组的经济性：** 变压运行时调速汽门全开，节流损失不同程度地降低 。  

**5. 汽轮机在启动、停机及变负荷过程中的受热特点有何不同？汽轮机的启停及变负荷受哪些因素的制约？**

- **受热特点的不同：** 汽轮机在启动过程中，与蒸汽相接触的金属表面热应力为压缩应力，另一面为拉伸应力；而停机过程的受力情况则正好相反 。  
- **启停及变负荷的制约因素：**
  - **热膨胀、热变形和热应力：** 运行中必须严格控制金属的温升速度、上下缸温差，以及转子与汽缸的相对膨胀（胀差），防止动静部分发生摩擦或部件翘曲变形 。  
  - **机组振动：** 需防止转子发生强烈振动（如弯曲振动和扭振），以免导致零件疲劳损坏、动静摩擦或直接造成机组事故 。  
  - **蒸汽品质：** 蒸汽品质不合格会腐蚀零件并在表面积垢，严重制约汽轮机的安全与寿命 。  
  - **综合因素：** 除了上述自身因素外，启停及负荷变动时间还受到热经济性和外界需求等多种因素的制约 。  

**6. 汽轮机正常运行维护的内容有哪些？**

根据文件内容综合，汽轮机的正常运行维护主要包括以下内容：

- **运行操作与经济调度：** 涉及日常运行操作以及适应电网需求的负荷变动与调峰调度 。  
- **受热与振动监测：** 严格控制热应力和差胀，防止汽轮机转子发生强烈振动 。  
- **蒸汽品质监控：** 经常对进入汽轮机的蒸汽品质进行监控，防止汽轮机本体及相关管道进水或积水，避免固体颗粒冲蚀汽流通道，防止通流部分积垢 。  
- **供油系统维护：** 确保为调节系统、保护系统、轴承润滑及盘车装置等提供可靠用油 。通过冷油器、滤油器和再生装置对油质进行过滤冷却，并定期清洗油箱内的磁性过滤器，以保持油质清洁完好 。
